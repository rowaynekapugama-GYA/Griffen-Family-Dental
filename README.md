# Griffin Family Dental — Digital Marketing Strategy & Launch Proposal

Interactive HTML proposal prepared by **Generate Your Audience (GYA)** for Griffin Family Dental, Freshwater Village, Griffin QLD (opening March 2027).

## Hosting via GitHub Pages

1. Create a new repository (e.g. `griffin-family-dental-proposal`) — set it to **Private** if you don't want it publicly indexed, or **Public** for free GitHub Pages hosting.
2. Upload the contents of this folder (`index.html`, `.nojekyll`, `README.md`).
3. Go to **Settings → Pages → Source: Deploy from a branch → main / (root)** and save.
4. The proposal will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

## Notes

- Single self-contained page — all CSS/JS is inline; charts (Chart.js), map (Leaflet/OpenStreetMap) and fonts (Google Fonts) load from CDNs, so the page needs an internet connection to render fully.
- `.nojekyll` prevents GitHub Pages from running Jekyll processing (not needed, but keeps things clean).
- To update content, edit `index.html` and push — Pages redeploys automatically.
